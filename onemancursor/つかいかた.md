# ワンマンカーソル（OneManCursor）のつかいかた

FinderSwipe（Finder のスワイプ操作＋カーソル共有）と AlwaysCursor（大きなカーソル表示）を合体させた、メニューバー常駐アプリです。
「カーソルは一人の運転士が全部のマシンを運転する」がコンセプトで、カーソル共有で操作を渡している間は、渡した側の大きなカーソル表示も自動で消えます（二重カーソルになりません）。

## できること

### Finder のスワイプ操作（旧 FinderSwipe）
アプリが有効で Finder が最前面のときだけ効きます。システム設定は変更しません。

| 操作 | 動作 |
|---|---|
| 2本指で右へフリック（速く・大きく） | 戻る（⌘[） |
| 2本指で左へフリック | 進む（⌘]） |
| 3本指で下スワイプ | 上の階層へ（⌘↑） |
| 3本指で上スワイプ | 開く（⌘O） |

### 相方モード
他のマシンとつながるための基盤です（発見と接続）。以前あった「Finder 以外でのスワイプを合図として送る」動作は、意図せず発動するため廃止しました。

### カーソル共有
画面の端で操作を隣のマシンに渡します。レイアウトはメニュー「レイアウト（相方の配置）」で方向ごとに設定します。転送は TCP 直結（ポート 45988、発見のみ UDP 45987）で、キー欠けが起きにくくなっています。渡している間、起点側のカーソルは渡した地点に固定されます。⌘Esc が非常口（セッション解除）。Esc 単体は普通のキーとして相手に送られます。

### レイアウトの変え方（手順）

レイアウトは「そのマシンから見た隣の位置」で、マシンごとに保存されます。変えるときは1台ずつ設定します。

1. 設定したいマシンで、アプリのメニュー「レイアウト（相方の配置）」を開く
2. 発見されている相手ごとに「右に置く／左に置く／上に置く／下に置く」を選ぶ
3. 隣り合う同士では互いに逆向きに設定する（例: MacBook の右に mini を置いたら、mini の左には MacBook を置く）
4. Windows は相手を自動で覚えるので、この設定は要りません

カーソル共有で相手の画面を操作しているときは、そのまま相手側のメニューを開いて設定できます。起点に戻りたいときは ⌘Esc でセッションをリセットしてください。

### カーソル表示（旧 AlwaysCursor）
- 「カーソルを大きく表示」: 本物のカーソルの上に大きなカーソルを重ねます（形は 矢印／丸／本物そっくり）
- 「カーソル表示の設定…」: 形ごとのサイズ・色・輪郭・ぼかし・不透明度、追従（先読み等）、Command 単独タップの波紋など
- カーソル共有で操作を渡している間は自動で消えます

## 最初にやること

1. **これまでの FinderSwipe と AlwaysCursor は終了してください**（両方動かすとジェスチャーもカーソル表示も競合します）
2. ビルド: `sh ~/Documents/OneManCursor/build.sh` → `OneManCursor.app` ができます
3. 起動すると、旧2アプリの設定（マシン ID、レイアウト、カーソルの形や色など）は初回起動時に自動で引き継がれます
4. 許可は**このアプリに対して改めて**必要です: システム設定 → プライバシーとセキュリティ → **アクセシビリティ** と **入力監視** で「ワンマンカーソル」を許可してください（メニューに開く項目があります）

## 注意

- 合図（UDP）とカーソル共有（TCP）に認証はありません。家庭内 LAN での利用を想定した試作です
- カーソル共有中は相手の画面で IME の変換中文字が正しく渡りません（英字入力推奨）
- 旧 FinderSwipe / AlwaysCursor は個別のアプリとして残してあります。ワンマンカーソルに問題があればそちらに戻れます
