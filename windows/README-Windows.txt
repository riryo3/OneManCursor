ワンマンカーソル Windows ピアのつかいかた
========================================

Mac のカーソル共有(ワンマンカーソル / FinderSwipe)を Windows にも広げるための、
タスクトレイに常駐する小さなプログラムです。Mac 側でワンマンカーソル(または FinderSwipe)が
動いている前提で使います。

■ 用意するもの
この ZIP の中身一式(OneManCursor.cs / build.bat / この文書)を、
Windows の適当なフォルダに置いてください。

■ ビルドと起動
1. build.bat をダブルクリック
   → Windows 標準の C# コンパイラで OneManCursor.exe ができます
2. OneManCursor.exe を起動
   - 初回はファイアウォールの許可を求められます。
     「プライベート ネットワーク」で許可してください
   - 窓は開かず、タスクトレイに「ワ」のアイコンで常駐します
   - 自分の ID は、トレイアイコンの右クリックメニューで確認できます
   - ログを見る: トレイの右クリック →「ログを表示」
   - 終了する:   トレイの右クリック →「終了」
   - 設定は同じフォルダの OneManCursor.ini に保存されます

■ 設定
基本は不要です。カーソルが入ってきた相手を「隣」として自動で覚え、
OneManCursor.ini に保存します(ini を手で編集する必要はありません)。
※ 以前の FinderSwipePeer.ini がある場合は、初回起動時に自動で
   OneManCursor.ini へ引き継がれます(ID と設定はそのまま使えます)

■ Mac 側の設定
- MacBook のレイアウトで、この Windows(トレイやログで確認できる名前)を
  「右に置く」にしてください

■ 使い方
- MacBook の右端からカーソルを押し出すと、Windows に操作が移ります
- Windows の左端に戻すと、MacBook に返ります
- Explorer が最前面ならスワイプ操作(戻る/進む など)も効きます

■ 注意
- 通信に認証はありません。家庭内 LAN 専用の試作です
- IME の変換中文字は正しく渡りません(英字入力推奨)
