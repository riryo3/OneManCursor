ワンマンカーソル Windows ピアのつかいかた
========================================

Mac のカーソル共有(ワンマンカーソル)を Windows にも広げるための、
タスクトレイに常駐する小さなプログラムです。Mac 側でワンマンカーソルが
動いている前提で使います。

■ 用意するもの
ビルド済みの OneManCursor.exe がある場合(Releases の OneManCursor-Windows.zip)は、
展開した OneManCursor.exe を適当なフォルダに置き、「起動」へ進んでください。

ソースからビルドする場合は、OneManCursor.cs / build.bat / この文書 を
Windows の適当なフォルダに置いてください。

■ ビルド(ソースから作る場合のみ)
build.bat をダブルクリックすると、Windows 標準の C# コンパイラで
OneManCursor.exe ができます。

■ 起動
OneManCursor.exe を起動します。
   - 「Windows によって PC が保護されました」(SmartScreen) が表示された場合:
     「詳細情報」をクリックし、「実行」を選択してください
   - 初回はファイアウォールの許可を求められます。
     「プライベート ネットワーク」で許可してください
   - 窓は開かず、タスクトレイに「ワ」のアイコンで常駐します
   - 自分の ID は、トレイアイコンの右クリックメニューで確認できます
   - 単独モード: トレイの右クリック →「単独モード」(オンの間は、カーソルが他の
     マシンへ出ていかず、届いたカーソルも送り返します)
   - ログを見る: トレイの右クリック →「ログを表示」
   - 終了する:   トレイの右クリック →「終了」
   - 設定は同じフォルダの OneManCursor.ini に保存されます

■ 設定
基本は不要です。隣の関係(レイアウト)は Mac 側で決めたものが自動で配られ、
OneManCursor.ini に保存されます(ini を手で編集する必要はありません)。
※ 以前の FinderSwipePeer.ini がある場合は、初回起動時に自動で
   OneManCursor.ini へ引き継がれます(ID と設定はそのまま使えます)
※ 更新するときは、トレイから終了してから exe を上書きしてください。
   フォルダごと入れ直すと ini が初期化され、マシンの ID が変わります

■ Mac 側の設定
- Mac のメニュー「レイアウトを編集…」を開くと、この Windows(トレイやログで
  確認できる名前)がタイルとして出ます。実際の並びに合わせてドラッグして
  置いてください。辺がくっついた相手が「隣」になります
- 配置は全マシン(この Windows を含む)へ自動で配られます。
  画面を開いただけでは配られないので、タイルを1つ動かしてください

■ 使い方
- 隣り合う Mac の画面の端からカーソルを押し出すと、Windows に操作が移ります
- Windows の画面の端から、隣のマシンの方向へ押し出すと、そのマシンへ移ります
- Explorer が最前面ならスワイプ操作(戻る/進む など)も効きます

■ 注意
- 通信に認証はありません。家庭内 LAN 専用の試作です
- IME の変換中文字は正しく渡りません(英字入力推奨)
